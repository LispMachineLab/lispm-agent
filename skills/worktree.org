#+title: Work in git worktrees
#+description: Delegate a change to a helper working in a git worktree of its own, on a branch of its own, so that parallel or risky work stays apart from your checkout until you merge it.

Agents share one Emacs and, by default, one checkout: what a helper started by ~ask_agent~
edits is edited in your files at once.  When that is not what you want, this skill gives the
helper a git worktree of its own: a second checkout of the same repository, on a new branch.
It needs git, and a project that is a git repository.

* When

- Several helpers change the same files at the same time, each on its own part of the work.
- A change you may not keep: an experiment, a large refactoring, a fix to try out.
- Work you want to review as a branch, as a whole, before it reaches your checkout.

Plain ~ask_agent~ is better for small changes you will keep, and for work that only reads.

* Delegating

~worktree_ask~ ROLE REQUEST [NAME] [BASE] makes a worktree in ~lispm-worktree-directory~
(~~/.lispm/worktrees/PROJECT/NAME/~), on the new branch ~lispm/NAME~ made from your ~HEAD~ or
from BASE, starts a helper of ROLE there in the background, and returns a request id
immediately so you stay free to continue other work or answer new input.
The helper may do no more than you, and retires once it has replied.  It is told to commit its
work on its branch.

Several ~worktree_ask~ calls in one step run side by side.  Give each a NAME that says what
it is for (~fix-parser~, ~try-cache~).

Changes you have not committed are not in the new worktree: commit what the helper must see
first.

The helper's project is yours: it shares your project's memory, tasks and session list, while
its turn journal is isolated per workspace so parallel turns and reverts never interfere.

* What comes back

When the helper finishes, its final reply arrives as a new inbox message (~[Reply to request
ID]~) with where its work is: the worktree, the branch, its commits, what it left
uncommitted, and the changes against the base.  A helper that changed nothing leaves nothing
behind: its worktree and branch are removed.

* Taking the work

With ~worktree_reconcile~ NAME (lock-free 3-way merge onto your branch ref via
~git merge-tree --write-tree~ and CAS ~git update-ref~) or with ~run_shell~ in your own
checkout:

- inspect changes: ~git log -p HEAD..lispm/NAME~, or ~git diff HEAD...lispm/NAME~;
- reconcile lock-free without touching the checkout: ~worktree_reconcile~ NAME (reports clean
  merge commit or exact conflicting files without leaving conflict markers in your checkout);
- or merge in your checkout once uncommitted changes are committed in the worktree
  (~git -C WORKTREE commit -am ...~);
- then ~worktree_remove~ NAME: it removes the worktree, and the branch once merged.

To drop the work instead, ~worktree_remove~ NAME with FORCE: its uncommitted changes and its
unmerged branch are deleted too.  Do that only when the work is not wanted, or the user says so.

~worktree_list~ shows the worktrees made so far, also those of earlier sessions.

* Care

- Reconcile or merge one helper's branch at a time; on a conflict, resolve it or ask the user.
- A worktree has the files git tracks, not the ignored ones: a helper may have to build or
  install what the project needs before running its tests.
- The user may want to see a branch before it is merged: say which, and where.

* The code

#+begin_src emacs-lisp :lispm load
(require 'lispm-workspace)
(require 'lispm-collab)

(defvar lispm-worktree-directory "~/.lispm/worktrees/"
  "Directory of the worktrees worktree_ask makes, each as PROJECT/NAME/.")

(defvar lispm-worktree-branch-prefix "lispm/"
  "Prefix of the names of their branches.")

(defun lispm-worktree--brief (path branch base request)
  "REQUEST, preceded by what a helper working in the worktree at PATH must know."
  (format "You work in a git worktree of your own, %s, on the branch %s, made from %s.  \
What you change there stays apart from the checkout of the agent asking until it merges \
your branch.  Commit your work on %s before you reply, if you may run git; what you leave \
uncommitted is reported as it is.\n\n%s"
          (abbreviate-file-name path) branch base branch request))

(defun lispm-worktree--format-list (trees acc callback)
  "Format remaining worktrees in TREES accumulating into ACC, then call CALLBACK."
  (if (null trees)
      (funcall callback (mapconcat #'identity (nreverse acc) "\n") nil)
    (pcase-let ((`(,name ,path ,branch) (car trees))
                (rest (cdr trees)))
      (if (not (file-directory-p path))
          (lispm-worktree--format-list
           rest
           (cons (format "- %s: branch %s, %s (missing)"
                         name (or branch "(none)") (abbreviate-file-name path))
                 acc)
           callback)
        (lispm-workspace-git-output
         path '("status" "--porcelain")
         (lambda (status err)
           (if err
               (funcall callback err t)
             (let ((line (format "- %s: branch %s, %s%s"
                                 name (or branch "(none)") (abbreviate-file-name path)
                                 (if (string-empty-p status) "" " (uncommitted changes)"))))
               (lispm-worktree--format-list rest (cons line acc) callback)))))))))

(lispm-deftool worktree_ask
    ((role string "The role to start the helper from (see list_agents).")
     (request string "What you need, self-contained: the helper cannot see your transcript.")
     (name string "Name of the worktree, and of its branch after lispm/; default: the role and a number."
           :optional t)
     (base string "Commit, branch or tag the branch starts from; default: your HEAD." :optional t))
  "Delegate a request in the background to a helper of ROLE working in a git
worktree of its own, on a new branch, and immediately return a request id.
The final reply and worktree summary arrive as a new inbox message; your
checkout is untouched meanwhile.  A helper that changed nothing leaves no
worktree or branch behind."
  :permission write
  :async t
  :concurrency 'parallel
  (let* ((me lispm-current-agent)
         (call lispm-current-call)
         (role* (or (lispm-get-role role t)
                    (error "No role named %s; list_agents shows the roles" role)))
         (root (lispm-agent-root me))
         (name (or name (format "%s-%04x" role (random #x10000))))
         (base (or base "HEAD")))
    (unless (string-match-p "\\`[[:alnum:]][[:alnum:]._-]*\\'" name)
      (error "A worktree name is letters, digits, dots, dashes and underscores"))
    (lispm-workspace-create
     root
     (lambda (ws err)
       (if err
           (funcall done err t)
         (condition-case dispatch-err
             (let* ((path (lispm-workspace-path ws))
                    (branch (lispm-workspace-branch ws))
                    (helper-root (lispm-workspace-effective-root ws))
                    (brief (lispm-worktree--brief path branch base request)))
               (funcall done
                        (lispm-collab-request me role* brief call helper-root :workspace ws)
                        nil))
           (error
            (ignore-errors (lispm-workspace-remove ws #'ignore :force t))
            (funcall done (error-message-string dispatch-err) t)))))
     :kind 'git-worktree
     :name name
     :base base
     :branch-prefix lispm-worktree-branch-prefix
     :directory lispm-worktree-directory)))

(lispm-deftool worktree_list ()
  "List the worktrees worktree_ask made in your repository: their names,
branches and places, and whether changes are left uncommitted there."
  :async t
  :concurrency 'parallel
  (lispm-workspace-list-worktrees
   (lispm-tools-root) lispm-worktree-directory
   (lambda (trees err)
     (cond
      (err (funcall done err t))
      ((null trees) (funcall done "No worktrees." nil))
      (t (lispm-worktree--format-list
          trees nil (lambda (text errorp) (funcall done text errorp)))))))
  nil)

(lispm-deftool worktree_remove
    ((name string "The worktree's name, as worktree_list shows it.")
     (force boolean "Discard the changes not committed there, and delete the branch even if not merged."
            :optional t))
  "Remove a worktree worktree_ask made, and its branch once merged into
yours.  Changes not committed there stop it, unless FORCE."
  :permission write
  :async t
  :concurrency (lambda (name &optional _force) (list 'resource (cons 'worktree name)))
  (let ((root (lispm-tools-root)))
    (lispm-workspace-list-worktrees
     root lispm-worktree-directory
     (lambda (trees err)
       (if err
           (funcall done err t)
         (let ((tree (assoc name trees)))
           (if (not tree)
               (funcall done (format "No worktree %s; worktree_list shows them" name) t)
             (if-let* ((ws (lispm-workspace-find-by-path (nth 1 tree))))
                 (condition-case rerr
                     (lispm-workspace-remove ws done :force force)
                   (error (funcall done (error-message-string rerr) t)))
               (condition-case rerr
                   (lispm-workspace-remove-worktree root (nth 1 tree) (nth 2 tree) force done)
                 (error (funcall done (error-message-string rerr) t)))))))))))

(lispm-deftool worktree_reconcile
    ((name string "The worktree's name, as worktree_list shows it.")
     (target string "Target branch or ref to update lock-free; default: current HEAD branch." :optional t)
     (commit_uncommitted boolean "Auto-commit uncommitted changes in the worktree before merging." :optional t))
  "Merge a worktree branch lock-free into TARGET via `git merge-tree --write-tree'
and CAS `git update-ref', without locking or altering your working tree."
  :permission write
  :async t
  :concurrency (lambda (name &optional _target _commit) (list 'resource (cons 'worktree name)))
  (let ((root (lispm-tools-root)))
    (lispm-workspace-list-worktrees
     root lispm-worktree-directory
     (lambda (trees err)
       (if err
           (funcall done err t)
         (let ((tree (assoc name trees)))
           (if (not tree)
               (funcall done (format "No worktree %s; worktree_list shows them" name) t)
             (let ((ws (or (lispm-workspace-find-by-path (nth 1 tree))
                           (lispm-workspace-for-worktree
                            root (nth 1 tree) (nth 2 tree) name))))
               (lispm-workspace-reconcile
                ws
                (lambda (res)
                  (pcase (plist-get res :status)
                    ('ok
                     (funcall done
                              (format "Reconciled %s into %s (%s%s)."
                                      name
                                      (plist-get res :target-ref)
                                      (substring (plist-get res :commit) 0 7)
                                      (if (plist-get res :fast-forward) ", fast-forward" ""))
                              nil))
                    ('noop
                     (funcall done
                              (format "Nothing to reconcile from %s into %s."
                                      name (plist-get res :target-ref))
                              nil))
                    ('conflict
                     (funcall done
                              (format "Conflicts merging %s into %s:\n%s\n\n%s"
                                      name (plist-get res :target-ref)
                                      (mapconcat (lambda (f) (concat "- " f))
                                                 (plist-get res :conflicts) "\n")
                                      (or (plist-get res :messages) ""))
                              t))
                    (_ (funcall done (or (plist-get res :error) "Reconcile failed") t))))
                :target-ref target
                :commit-uncommitted commit_uncommitted)))))))))
#+end_src
